# YouTube Intelligence RU

## Что это

Русскоязычная адаптация инструмента для **контент-разведки по YouTube**.

Простыми словами: это программа, которая по вашим темам и каналам сама ищет ролики на YouTube, собирает по ним данные (описания, субтитры, комментарии, метрики просмотров), а потом складывает всё это в понятный еженедельный отчёт в виде текстового файла. Из отчёта видно, какие темы заходят, какие боли и вопросы у аудитории, какие хуки работают, где назревают риски.

Кому полезно:

- **авторам и блогерам** — следить за темами, болями и хуками в своей нише;
- **маркетологам и предпринимателям** — смотреть, о чём говорят конкуренты и вся категория;
- **исследователям** — собирать локальный архив фактуры из публичных данных YouTube;
- **тем, кто строит ИИ-агентов** — получить простой файловый поток данных вместо очередной панели.

Что это **НЕ**:

- не обход блокировок и не взлом YouTube;
- не ферма ботов;
- не сборщик приватных данных;
- не облачный сервис «под ключ» — всё работает локально на вашем компьютере.

> Работает локально. Никакие ваши списки тем, ключи и собранные данные никуда не отправляются — всё лежит у вас на машине.

## Самый быстрый путь: через ИИ-ассистента

Если вы пользуетесь Claude Code (или другим агентом с доступом к терминалу), не обязательно вникать в команды. Скормите ассистенту этот репозиторий и дайте такой промпт:

> Установи инструмент из этого репозитория по инструкции в README (`pip install git+...`). Потом найди для меня свежие видео в нише **«ваша ниша»**: создай проект через `youtube-intel init`, запусти `youtube-intel full` с моим запросом, окном `--max-age-days 90`, `--limit-per-query 30`, `--min-views 300` и флагом `--skip-watchlist-channels`. Покажи готовый отчёт из папки `data/reports/`.

Ассистент сам выполнит установку и сбор. Замените «вашу нишу» на свою тему (например, «таргетированная реклама», «нейросети для дизайна», «запуск онлайн-школы»).

## Что вам понадобится

- **Python 3** (язык, на котором написана программа). Проверить: в терминале наберите `python3 --version`. Если команды нет — поставьте Python с [python.org](https://www.python.org/downloads/).
- **yt-dlp** — утилита, которая умеет тянуть данные с YouTube. Она ставится автоматически вместе с программой (см. ниже).
- **Терминал** — на Mac это приложение «Терминал», на Windows — PowerShell.

Всё бесплатно, никаких API-ключей YouTube не требуется.

## Установка и первый запуск

Скопируйте команды по одной в терминал.

```bash
# 1. Устанавливаем программу прямо из этого репозитория
python3 -m pip install "git+https://github.com/ffring/youtube-intelligence-ru.git"

# 2. Проверяем, что всё на месте (этот "доктор" скажет, чего не хватает)
youtube-intel doctor

# 3. Создаём рабочую папку проекта под свою задачу
youtube-intel init ~/youtube-intel-demo --template creator

# 4. Первый рабочий прогон от и до (подставьте свою нишу вместо запроса)
youtube-intel full ~/youtube-intel-demo --safe \
  --query "нейросети для маркетинга" \
  --limit-per-query 30 --max-age-days 90 --min-views 300 \
  --skip-watchlist-channels
```

Готовый отчёт появится в `~/youtube-intel-demo/data/reports/` — откройте свежий `.md`-файл.

Флаг `--safe` делает запуск «бережным»: ставит таймауты и не падает целиком, если YouTube где-то заартачился. `--limit-per-query 30 --max-age-days 90 --min-views 300` — это проверенные значения, при которых из одного ключевого слова стабильно возвращается непустой отчёт (см. ниже про свежесть).

Проверить, что `yt-dlp` на месте:

```bash
yt-dlp --version
```

## Как пользоваться

### Шаг 1. Создайте проект под свою нишу

```bash
youtube-intel init ~/моя-разведка --template creator
```

Внутри появится папка со списками для отслеживания:

```text
~/моя-разведка/
├── README.md
├── briefing.md
├── status.md
└── watchlists/
    ├── channels.yaml   ← каналы, за которыми следим
    └── topics.yaml     ← темы/запросы, которые ищем
```

Откройте `watchlists/topics.yaml` и `watchlists/channels.yaml` в любом текстовом редакторе и впишите свои темы и каналы.

**Шаблоны (`--template`):**

- `general` — широкий радар по рынку;
- `creator` — хуки, боли аудитории, форматы контента;
- `competitor` — альтернативы, переходы, жалобы на цены, риски площадки;
- `ai-tools` — исследование ИИ-инструментов и агентов.

### Шаг 2. Запустите сбор и отчёт

Самое простое — один прогон «всё сразу»:

```bash
youtube-intel full ~/моя-разведка --safe \
  --query "ваш запрос" \
  --limit-per-query 30 --max-age-days 90 --min-views 300 \
  --skip-watchlist-channels
```

Готовый отчёт появится здесь:

```text
~/моя-разведка/data/reports/
```

Откройте свежий `.md`-файл — это и есть ваш разбор ниши.

### Про «свежесть» — важно понимать

Поиск по ключевому слову у YouTube/`yt-dlp` сортируется **по релевантности, а не по дате**. Поэтому:

- **окно 90 дней (`--max-age-days 90`) — рабочее по умолчанию**: из одного запроса стабильно возвращается непустой отчёт по нише;
- если поставить строгое **`--max-age-days 30`**, результатов может остаться очень мало или ноль — это не поломка, а ограничение поиска YouTube (сортировки по дате там сейчас нет);
- **нужна именно свежатина за последние недели?** Самый надёжный способ — добавить конкретные каналы в `watchlists/channels.yaml`. Ленты каналов идут по дате (новые сверху), поэтому свежие загрузки ловятся точно. Тематический поиск — для широкого открытия ниши, каналы — для отслеживания свежего.

### Отдельные команды (если нужно по шагам)

```bash
youtube-intel doctor                      # проверка окружения
youtube-intel init <папка> --template creator   # создать проект
youtube-intel search <папка> --query "..."      # поиск роликов
youtube-intel transcripts <папка>               # собрать субтитры
youtube-intel comments <папка>                  # собрать комментарии
youtube-intel snapshots <папка>                 # снять метрики
youtube-intel report <папка>                    # собрать отчёт
youtube-intel full <папка>                       # всё сразу
```

### Полезные фильтры

```bash
# только свежие ролики, отсечь слабые по просмотрам/комментам
youtube-intel search ~/моя-разведка --query "ИИ агенты" --fresh-only --min-views 100 --min-comments 5

# отчёт только за последние 7 дней
youtube-intel report ~/моя-разведка --max-age-days 7 --min-views 100
```

- `--fresh-only` — оставить только свежие ролики (для поиска — за 7 дней). Строго: ролики без даты публикации отсекаются.
- `--max-age-days N` — оставить только ролики не старше N дней.
- `--min-views`, `--min-comments` — отсечь пустые/слабые результаты.

## Если YouTube требует «Sign in» / ловит на бота

При сборе данных YouTube иногда отдаёт ошибку:

```
ERROR: Sign in to confirm you're not a bot
```

На обычном домашнем интернете эта ошибка обычно **не возникает** — поиск работает сразу. Но на серверах, VPS и в облаке (Codespaces, Colab и т.п.) YouTube считает дата-центровые IP подозрительными и просит «войти». **Cookies и вход в аккаунт для обхода не нужны** — достаточно подсунуть `yt-dlp` правильный конфиг.

### Как починить

1. Создайте папку конфига `yt-dlp` (если её ещё нет) и скопируйте туда готовый пример из этого репозитория:

   ```bash
   mkdir -p ~/.config/yt-dlp
   cp config/yt-dlp.config.example ~/.config/yt-dlp/config
   ```

2. Готово. `yt-dlp` сам подхватит этот конфиг при следующем запуске.

Внутри конфига всего две строки:

```text
--extractor-args youtube:player_client=mweb,tv
--ignore-no-formats-error
```

Они говорят `yt-dlp` ходить на YouTube как мобильный (`mweb`) и ТВ-клиент (`tv`) — эти клиенты реже упираются в бот-защиту дата-центровых IP, и обходятся без cookies. (Проверено, работает.)

## Что важно знать (ограничения)

Это инструмент для исследования «на максимум возможного», а не гарантированный продукт.

- YouTube и `yt-dlp` могут меняться и ломаться: лимиты, ошибки `403`/`429`, региональные различия, удалённые ролики, возрастные ограничения.
- Субтитры собираются, только если они есть у ролика; комментарии — только если YouTube их отдаёт.
- `--fresh-only` и `--max-age-days` требуют известной даты публикации — ролики без даты в этих режимах отсекаются.
- Отчёт собирается «по формуле», без ИИ-домысливания и оценки достоверности источников.
- На маленькой выборке выводы делать рано — соберите больше роликов и комментариев.

## Безопасность данных

Даже из публичных источников можно собрать чувствительную выборку. **Не публикуйте папку `data/` своего проекта.**

Сам код в этом репозитории намеренно НЕ содержит:

- приватных списков отслеживания;
- расписаний задач (кронов);
- собранных субтитров/комментариев/отчётов;
- cookies, состояния браузера, API-ключей, `.env`-файлов;
- внутренних путей и заметок.
